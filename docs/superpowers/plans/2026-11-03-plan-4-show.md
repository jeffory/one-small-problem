# One Small Problem, Plan 4: Show Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The game is complete per the spec. The page opens on a title screen (ONE SMALL PROBLEM, one New Game option) with an immortal bot playing a fresh Moon behind it. New Game plays the never-leave-the-helmet opening: touchdown seen through the lander's triangular window, the crawl out of the hatch and down the ladder, the flag, the aliens, the silent white blast that breaks the lander apart, two seconds flat on your back looking at Earth, and the title drop. You then fight from the wreck through the crater and the base to the comms array, which puts you on hold for a 90-second final stand until Houston picks up, and an end screen shows your time, kills, golf balls and a share link. Mission Control talks in about 150 lines (speech plus subtitles, Quindar tones), every area has music, sounds are muffled in vacuum, and Esc pauses with settings. It still ships as one HTML file of at most 131,072 bytes; expect 65–85 KB.

**Architecture:**
- **Flow:** `src/main.js` becomes a small state machine over one *run* at a time: `title` (an attract run the bot drives) → `opening` → `play` → `ending` → `end` → `title`, with an orthogonal pause. A run is a world, its GPU scene, its fight, its wreck and, in play, its opening and radio. Scene swaps use the existing `dispose`. One function, `advance(dt, input)`, steps whichever state is current; the frame loop and the `ospTest.ff` hook both call it.
- **New pure modules** (Node-testable; no DOM, clock, GPU or `Math.random`):
  - `src/game/lander.js`: the detailed lander as 11 pre-cut pieces, and the seeded, fixed-step break-up
  - `src/game/opening.js`: the opening's beats, the cabin/hatch/ladder egress, the flag, the scripted aliens, the blast, the knock-down and the title drop
  - `src/game/hold.js`: the final stand's table and wave plan (the fight runs it)
  - `src/game/bot.js`: the attract bot
  - `src/game/script.js` and `src/game/radio.js`: the 150-line script, the triggers and the line queue
  - `src/ui/settings.js` and `src/ui/score.js`
- **Effectful edges:** `src/audio/{zzfx,sfx,audio,music,speech}.js` and `src/ui/menus.js`. Every audio and speech path degrades to silence plus subtitles.

## Global Constraints

**Carried from Plans 1–3 unchanged**
- **Output:** one self-contained `.html` file of at most **131,072 bytes** on disk. The build fails over the cap.
- **Runs from:** `https://` and `file://`. It makes no network requests except the universal decoder's re-fetch of its own file.
- **Packing:** `universalDecoder: true, compactHtml: false`. Keep the `<!doctype html>`.
- **Graphics:** WebGL2 only, with a half-float colour target via `EXT_color_buffer_float` and an RGBA8 fallback.
- **Code:** plain JavaScript with no runtime dependencies. Every file under `src/`, `tools/` and `build.mjs` is 7-bit ASCII. Use `\u` escapes in strings (`\u2026` for an ellipsis, `\u2014` for a dash) and CSS escapes (`\25CF`) in the shell.
- **Determinism in `src/gen/**`:**
  - Allowed: `+ - * /`, bit operations, `Math.imul/sqrt/floor/ceil/round/trunc/min/max/abs`.
  - Never: `Math.sin/cos/tan/asin/acos/atan/atan2/pow/exp/expm1/log*/hypot/cbrt/random`, `**`, `Date` or `.sort(`.
- **Coordinates:** metres, y up. The player faces −z at yaw 0, and forward is `(−sin yaw, −cos yaw)`. An alien or a piece with yaw `a` faces `(sin a, 0, cos a)`. Height-field sample `(i, j)` sits at world `(i − 256, j − 256)`; base tile `(i, j)` at `(i − 48, j − 48)`.
- **Simulation is pure:** these never touch `document.`, `window.`, `gl.`, `performance.now`, `Date.now` or `Math.random`:
  - `src/game/{weapons,bolts,nav,rigs,aliens,fight,models,areas,baseMesh}.js`
  - **new:** `src/game/{hold,bot,lander,opening,script,radio}.js` and `src/ui/{settings,score}.js`

  Each task that creates one adds it to `tests/purity.test.mjs`. Fight randomness comes from `F.rng = makeRng(world.seed + '/sim')`.
- **Sub-steps:** at most 0.05 s each, with a 0.25 s stall cap. One-shot inputs (`use`, `weapon`, `wheel`) apply on the frame's first sub-step only.
- **Per-frame render caps:** 16 point lights, 8 sphere occluders, 512 sprites. `fillFrame` allocates no `Float32Array` once warm.
- **Look:** 270 px internal height by default, the 51-colour palette with 4×4 Bayer dither, sun 1.55, vertical FOV 62°, exposure 1.
- **Names read from outside the bundle** (`window.ospTest`, GLSL uniforms, DOM ids) are never `_`-prefixed.
- **One way to build a world:** `generateWorld(seed)`. Generation does not change in this plan, so `tests/golden.test.mjs` stays green unchanged. A task that changes `src/gen` output must re-pin it in the same commit and say why.
- **Tuning tables** stay in tables: `WEAPONS`, `ALIENS`, `PICKUP`, `CANISTER`, `FALL`, `GRAVITY`, `WAKE`, `LIGHT`, `GUIDE`, plus the new `HOLD`, `ENDING`, `BOT`, `OPEN`, `EGRESS`, `WRECK`, `PIECES`, `RADIO`, `CUES`, `MIX`, `SFX`, `SONGS`. Tests read these constants, except for structural facts.

**New for Plan 4**
- **Flow:** title → opening → play → ending → end → title, plus pause. The opening plays only after the New Game button, never in attract mode, and never on a death.
- **URL:** only `history.replaceState` writes the hash, and only in two places:
  - New Game writes `#SEED`.
  - Going back to the title from the end screen or the pause menu clears it.

  The attract bot never touches the hash. A pasted link still reloads (the Plan 1 `hashchange` handler stays).
- **Storage:** `localStorage` is reached only through `src/ui/settings.js` (key `osp.settings`) and `src/ui/score.js` (keys `osp.best.<SEED>`). Both take a store argument, and every read and write is inside `try/catch`. `main.js` gets the store with `try { return localStorage; } catch { return null; }`.
- **Audio and speech never break the game:**
  - The game must run with any of these missing or throwing: `AudioContext`, `webkitAudioContext`, `OfflineAudioContext`, `speechSynthesis`, `SpeechSynthesisUtterance`, or any node method.
  - Every public method of `createAudio` and `createSpeech` catches its own errors.
  - Subtitles always show.
- **Look anti-goals (§2):**
  - UI text uses the shell's muted colours: `#b8ae9c` text, `#7a7266` dim and `#b8301a` alert, on black at most 0.6 opaque, with 1 px `#7a7266` button borders. No saturated UI, no gradients.
  - The blast flash mixes the image toward warm off-white `(.94, .91, .86)`. It holds at 1 for 0.12 s and fades over 1.2 s.
  - Foil glitter is small (0.045 m) and dim gold (at most `.9, .65, .22`).
  - No bloom.
- **Copy:** the radio script in Task 11 and every on-screen string in this plan are exact.
- **`ospTest` ships in release** (an earlier decision, confirmed by the user: the smoke tests need it). It reaches the current run, whatever the state.
- **Size:** expect about 65–85 KB after this plan. Above 100 KB, record a ruling with the cause.

## Review Focus

1. **No speech voices at all, or a voice whose `onend` never fires** (Chrome's online voices on Linux, espeak setups, headless browsers). Every line still shows its subtitle for its reading time, the queue never stalls, and story lines are never dropped. Tested in Task 11.
2. **Audio blocked or broken:**
   - no `AudioContext`, or one whose constructor or nodes throw
   - no `OfflineAudioContext`
   - a context suspended by autoplay rules

   The game plays silently with subtitles and logs no console errors. Tested in Tasks 9 and 10.
3. **Pausing mid-opening or mid-ending** (Esc or a lost pointer lock). Nothing advances while paused: not the opening's clock, the hold timer, the ending's countdown or the radio. The interrupted story line replays on resume. Tested in Tasks 5, 8 and 11.
4. **`localStorage` that throws or holds garbage** (private modes, `file://` in some browsers, older data). Settings and best times fall back to defaults with no errors. Tested in Tasks 2 and 3.
5. **The attract bot getting stuck, or a run that never ends.** The bot gives up after `BOT.stall` seconds without progress and starts a fresh Moon, and it never writes the URL hash. Tested in Task 4.

### Task 2: The flow: title, New Game, end screen, back to the title

`main.js` becomes the state machine. In this task the title's run stands still (the bot comes in Task 4), and New Game goes straight to play (the opening comes in Task 8). The end screen is reached through a test hook until Task 5 wires Houston.

**Files:**
- Create: `src/ui/score.js`, `src/ui/menus.js`, `tests/score.test.mjs`
- Modify: `src/main.js`, `src/ui/hud.js`, `src/shell.html`, `src/game/input.js`, `tests/smoke.spec.mjs`, `tests/purity.test.mjs`

**Interfaces:**
- **Produces, from `score.js`** (pure):
  - `fmtTime(s) => 'm:ss'`, with the seconds floored.
  - `shareLink(href, seed) => string | null`. It returns `href` up to its `#`, plus `'#' + seed`, or `null` when `href` starts with `file:`.
  - `recordBest(store, seed, time) => {best, isNew}`:
    - The key is `'osp.best.' + seed`, holding seconds as a string.
    - A missing or unparsable value counts as no best.
    - A lower time (or no best) is written, and gives `{best: time, isNew: true}`.
    - Otherwise it returns `{best: stored, isNew: false}`.
    - Any throw, or `store === null`, gives `{best: null, isNew: false}`.
- **Shell (`shell.html`), with exact ids and copy:**
  - `#title`: full screen, flex column, centred, `display:none` until shown, background `rgba(0,0,0,.35)`. It holds:
    - `h1#logo` reading `ONE SMALL PROBLEM`
    - `div#mission`, empty or `Mission #SEED`
    - exactly one `button#new` reading `New Game`
  - `#end`: full screen, `display:none`. It holds:
    - `h2` reading `MISSION REPORT`
    - `div#stats`, one `div` per line
    - `div#share`, holding `a#link` and `span#code` + `button#copy` (`Copy`)
    - `button#back` reading `Back to title`
  - The overlays take clicks. The HUD ids keep `pointer-events:none`.
  - `#msg` stays above everything for fatal errors.
- **Produces, from `menus.js`:**
  - `createMenus({onNew, onBack}) => { title(on, mission), end(report), hide() }`. Showing any overlay hides the others, and `hide()` hides them all.
  - `end(report)` writes these `#stats` lines in order:
    1. `TIME m:ss`
    2. `NEW BEST`, or `BEST m:ss` (left out when `best === null`)
    3. `KILLS n`
    4. `GOLF BALLS n/5`
  - With `report.link`, it shows `#link` (`href` and text are the link) and hides `#code` and `#copy`. Otherwise it shows `#code` (the seed) and `#copy`.
  - `#copy` calls `navigator.clipboard.writeText(seed)` with its rejection caught. Failing that, it selects `#code`'s text.
- **`hud.js`:**
  - `mode(m)` sets which HUD parts show:
    - `'none'`: none of `#stat`, `#prompt`, `#flash`, `#x` or the help line
    - `'opening'`: only `#prompt` and `#x`
    - `'play'`: all of them
  - `fatal()` also hides `#title` and `#end`, and later `#pause`, `#sub` and `#stamp`.
- **`input.js`:** gains `lock()`, the existing pointer-lock request with its catch. The canvas click handler uses it.
- **`main.js` (the state machine):**
  - `run = {kind: 'attract' | 'play', seed, world, scene, F}`. Later tasks add `bot`, `wreck`, `O` and `R`.
  - `state ∈ 'title' | 'opening' | 'play' | 'ending' | 'end'`.
  - `randomSeed()` is `seedName(makeRng(String(crypto.getRandomValues(new Uint32Array(1))[0])))`.
  - `startRun(kind, seed)`:
    - `world = generateWorld(seed)`, `scene = buildSurfaceScene(gl, world)` and `F = createFight(world)`
    - attract runs get `F.god = true`
    - `setScene(V, scene)`, then copy the eight frame fields
  - `stopRun()` calls `run.scene.dispose()`.
  - `newGame()`:
    1. `seed = normalizeSeed(location.hash) ?? randomSeed()`
    2. `history.replaceState(null, '', '#' + seed)` in `try/catch`
    3. `stopRun()`, then `startRun('play', seed)`
    4. `state = 'play'`; hide the title; `hud.mode('play')`; set the help line to `Click to look \u00b7 WASD move \u00b7 Shift run \u00b7 Space jump \u00b7 E use \u00b7 1-3 weapons \u00b7 mouse fire \u00b7 Esc pause`
  - The `#new` button calls `input.lock()`, then `newGame()`.
  - `toTitle(clear)`:
    1. `stopRun()`
    2. if `clear`, `history.replaceState(null, '', location.pathname + location.search)`
    3. `startRun('attract', randomSeed())`
    4. `state = 'title'`
    5. `menus.title(true, normalizeSeed(location.hash))`, and `hud.mode('none')`

    Boot calls `toTitle(false)`, so a shared link survives to New Game. `#back` calls `toTitle(true)`. **[call]** Going back to the title clears the seed, so the next New Game rolls a fresh Moon. Replaying a seed means opening its link.
  - `finish()`:
    1. `state = 'end'`
    2. `report = {time: F.time, kills: F.kills, golf: F.golf, link: shareLink(location.href, seed), seed, ...recordBest(store, seed, F.time)}`
    3. `menus.end(report)`, then `hud.mode('none')`
  - **[call]** The time is the fight's sim time from the start of play to the end. Deaths count; the opening and pauses do not. Kills are `F.kills`, the lifetime count, deaths included.
  - `advance(dt, inp)`:
    - `title` steps the attract fight with idle input. The bot comes in Task 4.
    - `play` and `ending` do what Plan 3's frame loop did: sub-steps, flashes and prompts.
    - Every state that steps a fight, the title's included, handles its level swap (Plan 3's `swap()`) for the current run.
    - `end` steps nothing.
  - The frame loop calls `advance`, then `fillFrame(V, run.F, frame, t)` and `render`. It keeps rendering in every state.
- **`window.ospTest`** is built once at boot; `ready` turns true after the first frame. It has:
  - `hdr`, `capture()`, `frames()` and `fault()`, as before
  - getter `seed`: the play run's seed, else `normalizeSeed(location.hash)`
  - getter `checksum`: `checksumWorld(run.world)` for a play run, else `null`
  - `state()`, `play()` (New Game without the pointer lock, and from Task 8 without the opening), `finish()`
  - `ff(sec, inp = {})`: calls `advance(1/30, {...IDLE, ...inp})` repeatedly for `sec` seconds, applying `inp` on every step. It does nothing while paused.
  - `player()`, `fight()` (which gains `time: F.time`), `area()`, `grab()`, `give()`, `door()`, `enter()`, `warp(k)` and `hurt(n)`, all acting on the current run

- **The rules `botStep` follows, in order:**
  1. **Done:** in area 3 without `finale`, set `done = 'comms'` and return idle.
  2. **The goal `(gx, gz)` and the distance left `rem`.** In each case below, a field "descent" means the best of the 8 neighbour cells, where a diagonal counts only if both its orthogonal neighbours are reached (as `fieldDir` does). `rem` is the field value there.
     - **Base level:** the goal is the descent of `baseField(B, commsDoor)`, computed once.
     - **Flag stage, flag not held:** the goal is the flag, and `use` is set within `BOT.use`. `rem` is the distance to it.
     - **Otherwise (the surface route):**
       1. Find the nearest segment `j ≥ k − 1` of `bot.path` in 2D. If `j ≥ k`, set `k = j + 1`. A bot knocked off the switchback onto a lower leg, or onto the crater floor, picks up from there.
       2. Advance `k` past waypoints within `BOT.wp`, except the last.
       3. The goal is `path[k]`. `rem` is the descent value of `bot.sf` at the player's cell.
       4. While stuck (`still ≥ BOT.stuck`), the goal becomes the `bot.sf` descent instead, which finds the way round bunkers, rims and ledges.
       5. In area 1, `use` is set within `DOOR_REACH − .5` of the use spot.
  3. **Progress:** a `rem` more than 1 m below the best so far resets the `still` timer and becomes the best. Otherwise `still += dt`.
     - Each time `still` passes a multiple of `BOT.stuck` (3, 6, 9 s…), spend 1 s with `jump` held and a random strafe side, and set the best to the current `rem`. A knock-back is forgiven once the bot starts winning ground back; a bot that can't get anywhere still stalls.
     - Past `BOT.stall`: `done = 'stall'`.
     - In `'hold'`, progress isn't tracked.
  4. **Target:** the nearest live alien within `BOT.sight` whose first sphere the eye can see. Every 0.5 s, draw an aim noise in ±`BOT.noise` for both yaw and pitch.
  5. **Turning:** the wanted yaw faces the target (with noise), or else the goal. Yaw and pitch move toward the wanted values by at most `BOT.turn·dt` each.
  6. **Moving:**
     - `fwd = cos(rel)` and `strafe = −sin(rel)`, where `rel` is the goal's bearing relative to the yaw. The bot outputs analog values, which the controller already accepts.
     - With a target: add a strafe of ±0.6 that flips every `BOT.strafe` s, and set `run = false`.
  7. **Firing:**
     - `fire` when the angle between the view and the target is under `BOT.fire`, and either the weapon is a gun or the target is within 2.4 m.
     - Weapon choice: the scattergun if owned with at least 4 cells and the target within 10 m; else the pistol if owned with at least 1 cell; else the pole.

export function segmentHits(tris, a, b) { const d = [b[0] - a[0], b[1] - a[1], b[2] - a[2]], sub = (u, v) => [u[0] - v[0], u[1] - v[1], u[2] - v[2]];
  const cr = (u, v) => [u[1] * v[2] - u[2] * v[1], u[2] * v[0] - u[0] * v[2], u[0] * v[1] - u[1] * v[0]], dt = (u, v) => u[0] * v[0] + u[1] * v[1] + u[2] * v[2];
  for (const [p0, p1, p2] of tris) { const e1 = sub(p1, p0), e2 = sub(p2, p0), h = cr(d, e2), q = dt(e1, h); if (Math.abs(q) < 1e-12) continue;

This is ZzFX's micro sample generator, with ZzFX 1.x's parameter order: `volume, randomness, frequency, attack, sustain, release, shape, shapeCurve, slide, deltaSlide, pitchJump, pitchJumpTime, repeatTime, noise, modulation, bitCrush, delay, sustainVolume, decay, tremolo`.
  - Port it as written below. The MIT notice stays in the file. `Math.random` is fine here: it is audio, not simulation. A pre-flight run of this exact code rendered every SFX below with peaks of 0.15–1.0 and no NaNs.
    ```js
    // ZzFX - Zuper Zmall Zound Zynth - Micro Edition
    // MIT License - Copyright 2019 Frank Force (https://github.com/KilledByAPixel/ZzFX)
    export const ZZFX_RATE = 44100;
    export function zzfxG(volume = 1, randomness = .05, frequency = 220, attack = 0, sustain = 0, release = .1, shape = 0, shapeCurve = 1, slide = 0, deltaSlide = 0,
      pitchJump = 0, pitchJumpTime = 0, repeatTime = 0, noise = 0, modulation = 0, bitCrush = 0, delay = 0, sustainVolume = 1, decay = 0, tremolo = 0) {
      const R = ZZFX_RATE, PI2 = Math.PI * 2, sign = v => v > 0 ? 1 : -1;
      let startSlide = slide *= 500 * PI2 / R / R, startFrequency = frequency *= (1 + randomness * 2 * Math.random() - randomness) * PI2 / R,
        b = [], t = 0, tm = 0, i = 0, j = 1, r = 0, c = 0, s = 0, f, length;
      attack = attack * R + 9; decay *= R; sustain *= R; release *= R; delay *= R; deltaSlide *= 500 * PI2 / R ** 3;
      modulation *= PI2 / R; pitchJump *= PI2 / R; pitchJumpTime *= R; repeatTime = repeatTime * R | 0;
      for (length = attack + decay + sustain + release + delay | 0; i < length; b[i++] = s) {
        if (!(++c % (bitCrush * 100 | 0))) {
          s = shape ? shape > 1 ? shape > 2 ? shape > 3 ? Math.sin((t % PI2) ** 3) : Math.max(Math.min(Math.tan(t), 1), -1) : 1 - (2 * t / PI2 % 2 + 2) % 2
            : 1 - 4 * Math.abs(Math.round(t / PI2) - t / PI2) : Math.sin(t);
          s = (repeatTime ? 1 - tremolo + tremolo * Math.sin(PI2 * i / repeatTime) : 1) * sign(s) * Math.abs(s) ** shapeCurve * volume *
            (i < attack ? i / attack : i < attack + decay ? 1 - (i - attack) / decay * (1 - sustainVolume) : i < attack + decay + sustain ? sustainVolume
              : i < length - delay ? (length - i - delay) / release * sustainVolume : 0);
          s = delay ? s / 2 + (delay > i ? 0 : (i < length - delay ? 1 : (length - i) / delay) * b[i - delay | 0] / 2) : s;
        }
        f = (frequency += slide += deltaSlide) * Math.cos(modulation * tm++);
        t += f - f * noise * (1 - (Math.sin(i) + 1) * 1e9 % 2);
        if (j && ++j > pitchJumpTime) { frequency += pitchJump; startFrequency += pitchJump; j = 0; }
        if (repeatTime && !(++r % repeatTime)) { frequency = startFrequency; slide = startSlide; j = j || 1; }
      }
      return new Float32Array(b);
    }

- **Produces, from `radio.js`** (pure):
  - The table:
    ```
    RADIO = { key: .25, gap: .5, min: 1.6, cps: 14, slack: 1.5, pad: 2, stale: 5, chat: 4, low: 30, dawdle: 50, multi: [3, 4] }
    ```
  - `createRadio(rng, script = SCRIPT, cues = CUES) => R`:
    - `R.clock` is the radio's own clock, advanced only by `stepRadio`.
    - `R.q` is the queue of lines `{id, key, who, text, crit, at, voiced}`. Critical lines come first, then at most one reaction.
    - `R.cur` is the playing line and `R.phase ∈ 'idle' | 'key' | 'talk' | 'unkey' | 'gap'`.
  - `radioCue(R, key, n) => boolean`. It returns `false` for any of these:
    - an unknown key
    - a `once` key already used
    - a key still cooling down (`R.clock` before the key's next allowed time)
    - a chance roll that misses: with `p < 1`, `rng.next() ≥ p`

    Otherwise it picks the lines:
    - `seq`: all of them, in order
    - `at`: line `n − 1`
    - otherwise one line from a shuffle-bag (`rng.int` over the unused lines, refilled when empty)

    Then it queues them:
    - `seq` and `crit` lines join the critical part of the queue, after the critical lines already there.
    - A reaction replaces any waiting reaction: the newest wins.

    It stamps `at = R.clock`, sets the cooldown, marks `once`, and returns `true`.
  - `radioEvents(R, events, F)` maps fight events to cues. Only one cue fires per kill event.

    | Event | Cue |
    |---|---|
    | `kill` | `first` when `F.kills === 1`; else `multi` when this is the third kill within 4 s (`RADIO.multi`), which also clears the count; else `brute` for `br`; else `floater` for `fl`; else `kill` |
    | `hurt` | `fall` for cause `fall`; else `low` when `F.hp < RADIO.low` and `F.state === 'play'` |
    | `pickup` | `e.kind` (`pistol`, `scatter`, `tape` or `cells`) |
    | `flag` | `grab` |
    | `golf` | `('golf', e.n)` |
    | `area` | `e.id`, for `crater`, `base` and `comms` |
    | `dead` | `dead` |
    | `restart` | `restart` |
    | `boom` | `boom` |
    | `hold` | `hold` |
    | `holdmsg` | `holding` |
    | `houston` | `houston` |

    The progress events `kill`, `pickup`, `flag`, `golf`, `area`, `restart` and `hold` zero the dawdle clock.
  - `stepRadio(R, dt, voiced, dawdle) => actions`. In order:
    1. `R.clock += dt`.
    2. While `dawdle` is set, the dawdle clock grows. At `RADIO.dawdle` it cues `dawdle` and restarts.
    3. A waiting reaction older than `RADIO.stale` is dropped.
    4. At most one phase transition happens:
       - **idle → key:** when the queue's head is critical, or `R.clock` is past the quiet time. It takes the line, notes `line.voiced = voiced`, and returns `{do: 'key', line}`.
       - **key → talk**, after `RADIO.key`: returns `{do: 'say', line}`.
       - **talk → unkey:** returns `{do: 'unkey'}`. Talk ends at:
         - voiced: onend has been reported and at least `RADIO.min` has passed, or the fallback `RADIO.slack·len/RADIO.cps + RADIO.pad` has
         - unvoiced: `max(RADIO.min, len/RADIO.cps)`
       - **unkey → gap**, after `RADIO.key`: returns `{do: 'off'}`. After a reaction, the quiet time becomes `R.clock + RADIO.chat`.
       - **gap → idle**, after `RADIO.gap`.
  - `radioDone(R, id)`: reports onend for line `id`. A mismatched id (a stale onend) is ignored.
  - `pauseRadio(R) => actions`:
    - In key or talk: a critical line goes back to the queue's head, to replay from the start; a reaction is dropped. The state returns to idle, and it returns `[{do: 'off'}]`.
    - In unkey: it returns `[{do: 'off'}]` without requeueing.
    - Otherwise: `[]`.
  - `radioIdle(R)`: no current line, an empty queue, and the phase idle or gap.
- **Produces, from `speech.js`:** `createSpeech(win = globalThis) => {ok, say(line, onEnd), cancel(), volume(v)}`. Every method catches its own errors.
  - **`ok`** is a live getter: true once a voice is chosen. It is never awaited: lines start unvoiced until a voice exists.
  - **Choosing a voice:** read `getVoices()` at creation, and again on every `voiceschanged`. Prefer an `en*` `localService` voice, then any `en*` voice, then the first voice. **[call]** This is the spec's "wait for `voiceschanged` with a timeout": nothing waits at all.
  - **`say`:**
    1. `speechSynthesis.cancel()`
    2. `new SpeechSynthesisUtterance(text)`, with the voice, its `lang`, `[pitch, rate] = VOICE[who]` and the set volume
    3. `onend` and `onerror` each call `onEnd` at most once, between them
    4. `speak`

    It returns `false` if there is no `speechSynthesis` or anything throws.
- **Shell and HUD:**
  - `#sub` is fixed at the bottom centre (12% up), with `max-width:70vw` and `pointer-events:none`.
